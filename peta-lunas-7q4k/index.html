🗺️ Peta Lunas Utang

Peta jalan bebas paylater, pinjol & kartu kredit. Bisa dibuka di Google Sheets (HP & laptop) maupun Excel.

⬇️ Unduh Template

📱 Buka di HP (Google Sheets)

  1. Tekan tombol Unduh Template di atas.
  2. Buka aplikasi Google Spreadsheet (pasang dari Play Store/App Store kalau belum ada).
  3. Tekan ikon folder di kanan atas → pilih file Peta-Lunas-Utang.xlsx dari folder Download.
  4. Kalau muncul tulisan mode kompatibilitas, tekan titik tiga → Simpan sebagai Google Spreadsheet.

💻 Buka di laptop

  1. Unduh template, lalu buka drive.google.com.
  2. Klik Baru → Upload file → pilih Peta-Lunas-Utang.xlsx.
  3. Klik dua kali filenya → menu File → Simpan sebagai Google Spreadsheet.
  4. Pakai Excel? Cukup klik dua kali file hasil unduhan.

✅ Cara pakai (5 menit)

  1. Sheet Daftar Utang: ganti contoh dengan utangmu di kolom kuning.
  2. Isi uang yang sanggup kamu sisihkan per bulan, pilih strategi Snowball atau Avalanche.
  3. Sheet Rencana Lunas: lihat tanggal bebas utang & bunga yang kamu hemat.
  4. Sheet Jadwal Bayar: tiap bulan bayar sesuai angka, lalu tandai ✅.
